این پوشه فقط فایل‌های لازم اجرای سایت و پنل مدیریت را دارد.

1) محتویات همین پوشه را در ریشه Repository گیت‌هاب قرار دهید.
2) از همین Repository دو Service در Railway بسازید.

SERVICE 1 — سایت اصلی
Start Command: npm run start:site
هدف پورت: 8080
Variables:
DATA_DIR=/data
ADMIN_URL=https://آدرس-پنل-مدیریت
ADMIN_API_KEY=یک-کلید-داخلی-طولانی-و-تصادفی

یک Railway Volume به مسیر /data متصل کنید تا گزارش‌ها و آمار بعد از Redeploy باقی بمانند.

SERVICE 2 — پنل مدیریت
Start Command: npm run start:admin
هدف پورت: 8000
Variables:
SITE_API_URL=https://آدرس-سایت-اصلی
ADMIN_PASSWORD=admin
ADMIN_API_KEY=دقیقاً-همان-کلید-داخلی-سرویس سایت

رمز ورود پنل: admin

ویژگی‌های امنیتی و داده:
- گزارشات عمومی قابل خواندن نیستند و فقط بعد از ورود مدیر در پنل نمایش داده می‌شوند.
- گزارش‌ها حذف خودکار ندارند و در SQLite ذخیره می‌شوند.
- پنل Session، HttpOnly Cookie، SameSite، محدودیت تلاش ورود و هدرهای امنیتی دارد.
- سایت و پنل HTTPS را پشت دامنه Railway استفاده می‌کنند.
- هیچ نرم‌افزاری را نمی‌توان 100٪ غیرقابل‌هک تضمین کرد؛ برای امنیت واقعی ADMIN_API_KEY را تصادفی و طولانی انتخاب کنید و HTTPS را نگه دارید.
- گزارش جدید پنل تقریباً هر 1 ثانیه بررسی می‌شود و در صورت ورود گزارش جدید، اعلان نمایش داده می‌شود.
- عنوان خوش‌آمدگویی پنل بین «سلام، خوش آمدی» و «محمدرضا فتح آبادی» هر 1 ثانیه تغییر می‌کند.

تست سلامت:
SITE /health
ADMIN /health
